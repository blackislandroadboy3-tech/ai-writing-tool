## 分類（OWASP Top 10 for LLM Applications 2025）

| ID | 名前 | このチェックでの主な例 |
|---|---|---|
| LLM01 | プロンプトインジェクション | アップロード文書・取得した Web ページ・メール中の指示 |
| LLM02 | 機密情報の漏えい | APIキー、会話・個人情報の保存や共有、利用者間の混在 |
| LLM03 | サプライチェーン | 依存ライブラリ、pickle / trust_remote_code |
| LLM05 | 不適切な出力の扱い | unsafe_allow_html、出力を exec / SQL / パスに使用 |
| LLM06 | 過剰な権限 | コード実行・ファイル書き込み・HTTP のツール |
| LLM07 | システムプロンプトの漏えい | システムプロンプト内の秘密 |
| LLM10 | 無制限の消費 | 認証・回数制限・トークン上限なし |

LLM04（データ・モデル汚染）、LLM08（ベクトル・埋め込み）、LLM09（誤情報）は、学習や RAG を行うアプリでだけ確認する。LLM と関係ない問題（Streamlit 設定、.gitignore）は「一般」と書く。
